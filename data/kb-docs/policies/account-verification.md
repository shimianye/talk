# 账户验证与身份核验规则

> 文档版本：V1.0  
> 生效日期：2026-09-01  
> 适用范围：客服系统所有涉及用户数据的操作

## 一、验证原则

1. **谁主张谁验证**：用户要求查询、修改、操作任何账户相关数据前，必须验证其身份。
2. **最小验证**：根据操作风险等级选择验证方式，低风险操作可简化验证。
3. **验证留痕**：所有身份验证操作记录日志，包括验证方式、验证结果、操作人。
4. **验证失败处理**：连续验证失败达到阈值时，锁定操作并转人工。

## 二、风险等级与验证方式

| 操作类型 | 风险等级 | 所需验证方式 |
|----------|----------|-------------|
| 查询商品参数、店铺政策 | 无风险 | 无需验证 |
| 查询自己的订单状态 | 低风险 | 登录态验证（已登录即可） |
| 查询订单物流详情 | 低风险 | 登录态 + 订单号 |
| 修改收货地址（未发货） | 中风险 | 登录态 + 手机号验证码 |
| 申请退货/退款 | 中风险 | 登录态 + 订单号 + 手机号验证码 |
| 查询完整收货地址/手机号 | 中风险 | 登录态 + 手机号验证码 + 客服确认 |
| 申请价保补差 | 中风险 | 登录态 + 订单号 |
| 取消订单 | 中风险 | 登录态 + 手机号验证码 |
| 修改账户手机号 | 高风险 | 原手机号验证码 + 新手机号验证码 + 身份证后4位 |
| 重置支付密码 | 高风险 | 手机号验证码 + 身份证后4位 + 人脸识别 |
| 注销账户 | 高风险 | 手机号验证码 + 身份证后4位 + 人工确认 |
| 批量导出个人数据 | 高风险 | 手机号验证码 + 身份证后4位 + 主管审批 |
| 投诉/索赔超过1000元 | 高风险 | 登录态 + 人工客服核实身份 |

## 三、验证方式说明

### 3.1 登录态验证

- 用户已在 App/网页登录，系统通过 Session/Token 确认身份。
- 登录态有效期：7 天（记住登录），关闭浏览器后失效（未记住）。
- 异地登录需额外手机号验证。

### 3.2 手机号验证码

- 向用户预留手机号发送 6 位数字验证码。
- 验证码有效期：5 分钟。
- 连续错误 5 次，锁定 30 分钟。
- 同一手机号 1 分钟内最多发送 1 次，1 小时内最多 5 次。

### 3.3 订单号验证

- 用户提供订单号，系统校验该订单是否属于当前登录账户。
- 订单号格式：ORD + 11 位数字。
- 订单号不属于当前账户的，拒绝查询并提示"订单号有误或不属于本账户"。

### 3.4 身份证后4位验证

- 用户提供身份证号后 4 位，与账户实名信息比对。
- 仅用于高风险操作，不要求提供完整身份证号。
- 未实名认证的账户需先完成实名认证。

### 3.5 人脸识别

- 仅用于重置支付密码等高风险操作。
- 调用第三方实名认证接口，比对身份证照片和实时人脸。
- 识别失败可重试 3 次，超过后转人工审核。

## 四、客服场景验证流程

### 4.1 用户进线查询订单

```
用户：我的订单到哪了？
客服：请提供您的订单号，或确认您的登录手机号后4位。
用户：ORD202609001 / 手机后4位 5678
客服：[系统校验订单归属] → 验证通过，查询物流信息
```

### 4.2 用户要求修改地址

```
用户：帮我改一下收货地址
客服：为保障账户安全，需要验证您的身份。已向您的手机 138****5678 发送验证码，请提供。
用户：123456
客服：[验证通过] 请提供新的收货地址。
```

### 4.3 用户查询他人订单（越权拦截）

```
用户：帮我查一下 ORD202609002 的物流
客服：[系统校验：该订单不属于当前账户]
客服：抱歉，该订单号与您的账户不匹配，我无法查询他人订单信息。
      请确认订单号是否正确，或使用下单账户登录后查询。
```

## 五、验证失败处理

| 失败次数 | 处理方式 |
|----------|----------|
| 1-2 次 | 提示重新输入，不锁定 |
| 3 次 | 提示"还有2次机会"，建议核对信息 |
| 5 次 | 锁定该操作 30 分钟，记录安全事件 |
| 同一账户 24 小时内累计 10 次 | 临时冻结账户，需人工解冻 |

## 六、特殊场景

### 6.1 用户无法接收验证码

- 手机号已停机/换号：需提供身份证照片 + 原手机号 + 新手机号，人工审核后修改。
- 海外用户无法接收短信：可使用邮箱验证码（需预先绑定邮箱）。

### 6.2 家属代为咨询

- 家属来电咨询他人订单的，需订单本人授权（电话中本人确认或书面授权）。
- 无法联系本人的，客服仅提供通用政策解答，不透露具体订单信息。

### 6.3 企业采购订单

- 企业订单需验证企业联系人身份（手机号 + 企业名称 + 订单号）。
- 企业订单的发票、退款操作需企业授权人确认。

## 七、智能客服验证要求

1. AI 客服在处理中高风险操作前，必须主动触发身份验证流程。
2. AI 不得在未验证身份的情况下输出用户的完整手机号、地址、订单金额。
3. AI 检测到用户试图绕过验证（如套取、社工攻击）时，拒绝并转人工。
4. AI 验证流程中不得存储验证码明文，验证后立即销毁。
