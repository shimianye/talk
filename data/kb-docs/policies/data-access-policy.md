# 数据访问权限策略

> 文档版本：V1.0  
> 生效日期：2026-09-01  
> 适用范围：客服系统所有用户数据访问场景

## 一、核心原则

1. **用户只能查询自己的订单**：任何用户（包括客服）不得查询他人的订单、地址、联系方式等个人信息。
2. **最小权限原则**：每个角色只能访问完成其工作所必需的最少数据。
3. **全程审计**：所有敏感数据访问操作均记录日志，包括访问人、时间、数据类型、访问原因。
4. **按需授权**：数据访问权限需申请并审批，不默认开放。

## 三、客服数据访问规则

### 3.1 在线客服

1. 客服只能在用户主动进线并提供订单号后，查询该订单的必要信息。
2. 客服界面默认脱敏显示手机号和地址，需点击"查看完整信息"并填写原因后才能显示。
3. 客服不得将用户信息复制、截图、导出到外部系统。
4. 客服不得查询与当前会话无关的订单。
5. 单次会话中查询超过 5 个不同用户订单的，系统自动预警并记录。

### 3.2 客服主管

1. 主管可查看客服的会话记录和处理的工单。
2. 主管可查看脱敏后的用户信息用于质检和投诉处理。
3. 主管导出数据需上级审批，导出文件加密且 7 天后自动删除。

### 3.3 仓库人员

1. 仓库人员只能查看待发货订单的收货信息（姓名、地址、手机号），用于打印面单。
2. 仓库人员不得查看订单金额、支付方式、用户历史订单。
3. 面单打印后系统自动脱敏，仓库界面不保留完整地址。

## 四、越权访问处理

1. 系统检测到越权访问尝试时，自动拦截并记录安全事件。
2. 单次越权：警告 + 记录；月度累计 3 次：暂停权限 + 调查。
3. 故意查询他人隐私数据的，立即停用账号并按公司制度处理。
4. 涉嫌违法的，保留证据并移交相关部门。

## 五、API 数据接口权限

1. 所有数据 API 需携带有效的访问令牌（Token）。
2. Token 绑定角色和 IP 白名单，异常 IP 调用自动拒绝。
3. API 返回的用户数据默认脱敏，需额外申请"完整数据"权限。
4. API 调用频率限制：普通接口 100 次/分钟，敏感接口 10 次/分钟。

## 六、数据保留与删除

1. 用户注销账户后，个人数据在 30 天内删除（法律法规要求保留的除外）。
2. 订单数据保留 3 年后匿名化处理（删除姓名、手机号、地址，保留商品和金额用于统计）。
3. 客服会话记录保留 1 年，超过后自动删除。
4. 审计日志保留 3 年，用于安全追溯。
