## 未完成的外部验证

真实 24 条 DeepSeek 评测尚未执行。项目 `.env` 已配置模型，但独立评测依赖 PostgreSQL/pgvector。Docker Desktop 4.80 在本机启动时崩溃，日志错误为：

```text
initializing Inference manager: ... dockerInference:
The file cannot be accessed by the system.
```

诊断发现 `C:\Users\Administrator\AppData\Local\Docker\run\dockerInference` 是零字节 reparse point；当前执行环境不允许删除该 Docker 运行态对象或启动系统服务。评测未发出任何 DeepSeek 请求，也没有填写虚构指标。

Docker 恢复后的唯一运行命令：

```powershell
cd D:\develop\phone-commerce-agent
docker compose up -d --build
docker compose exec api python scripts/bootstrap.py
docker compose exec api python -m eval.run_eval --job-slice
```

运行前应确认 `api` 容器读取 `LLM_PROVIDER=deepseek`。最多执行这一轮 24 条，并把生成报告中的分母、模型与切片哈希同步到 README。
