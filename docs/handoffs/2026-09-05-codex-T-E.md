## 完成内容

- 新增 GitHub Actions workflow，触发条件为 `push main`、`pull_request main` 和手工 `workflow_dispatch`。
- 使用 `pgvector/pgvector:pg16` 与 `redis:7-alpine` service containers，并同时配置容器 health check 和 runner 主动探测。
- 设置 `LLM_PROVIDER=mock`、`EMBEDDING_PROVIDER=mock`，CI 不读取或注入 DeepSeek 密钥。
- 在 bootstrap 前创建 T-A/T-C 破坏性集成测试所需的两个临时数据库：`phone_commerce_migration_test`、`phone_commerce_bootstrap_test`。这是对建议骨架中遗漏项的必要修正。
- 调用 T-C `scripts/bootstrap.py` 初始化主库与评测库。
- 调用完整 pytest，并调用 T-D `python -m eval.run_eval --output-dir reports --fail-on-errors` 跑 100 条 Mock 评测。
- 使用 `actions/upload-artifact@v4` 上传 `backend/reports/`，保留 30 天；失败时将最近报告摘要写入 GitHub Step Summary。
- CI workflow 未修改任何业务代码、评测集、迁移或 seed/kb 同步路径。
